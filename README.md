# Reader Diary

Учебный full-stack проект по теме "Веб-приложение для учета и планирования чтения книг".

## Что уже заложено

- регистрация и аутентификация пользователей через JWT;
- личная библиотека с книгами и статусами `Читаю`, `Прочитано`, `Отложено`;
- фиксация чтения по сессиям: дата, минуты, страницы, автообновление прогресса;
- заметки и цитаты по книгам;
- экспорт записей по книге в `Markdown`, `TXT` и `JSON`;
- графики `страниц в день` и `книг в год`;
- рекомендации на основе завершенных книг и оценок;
- SQLite-база с демонстрационным каталогом примерно на 100 книг.

## Структура

- `client` - React + Vite интерфейс.
- `server` - Node.js + Express API + SQLite.
- `docs/architecture.md` - базовый план архитектуры и дальнейших этапов.

## Быстрый старт

```bash
npm.cmd install
npm.cmd run dev
```

Клиент: `http://localhost:5173`

API: `http://localhost:4000`

## Запуск в Windows

Если в `PowerShell` команда `npm` блокируется политикой выполнения, используйте `npm.cmd`.

Запуск сразу клиента и сервера:

```bash
npm.cmd start
```

Или по отдельности в двух окнах:

```bash
npm.cmd run start:server
npm.cmd run start:client
```

Также можно запускать через готовые Windows-файлы:

- `start-app.cmd` - открыть клиент и сервер в двух окнах;
- `start-server.cmd` - только API;
- `start-client.cmd` - только React-клиент.
